# Security Policy

## Scope & Purpose

`@gykh/vigenere-cipher` is an educational and utility library implementing the classical Vigenère substitution cipher.

> [!WARNING]
> The Vigenère cipher is a 16th-century polyalphabetic substitution cipher and is **not cryptographically secure** against modern cryptanalysis. It should not be used to protect sensitive data or passwords in production systems.

## Reporting a Vulnerability

If you discover a vulnerability or denial-of-service issue in the implementation (e.g. infinite loop, memory exhaustion, unexpected crash), please report it responsibly by contacting:

* **Email**: sylvester.das@gmail.com
* **GitHub Issues**: https://github.com/get-your-knowledge-here/vigenere-cipher/issues
